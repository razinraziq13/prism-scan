# Prism Scan

A colorful document scanner that runs entirely in the browser and installs on iPhone as a home-screen app (PWA).

- 📷 Scan with the camera or import from Photos (several at once)
- ✨ Automatic page-edge detection (OpenCV.js) with draggable corners and a zoom loupe
- 🪄 Perspective straightening
- 🎨 Filters: Magic, Original, Gray, B&W, Vivid
- ✍️ Signatures: draw once (4 ink colours), save, drag/resize onto any page, undo anytime
- 📕 Multi-page PDF export (jsPDF)
- 🔤 Text recognition / OCR in 11 languages (Tesseract.js)
- 🔒 Everything stays on the device (IndexedDB). Works offline after first use.

## Install on iPhone

▶️ Watch the [install tutorial](https://razinraziq13.github.io/prism-scan/tutorial.html), or download the MP4 for [iPhone](tutorial.mp4) or [Android](tutorial-android.mp4).

1. Open the GitHub Pages link in **Safari**.
2. Tap **•••** (or **Share**) → **Add to Home Screen** → **Add**.

## Install on Android

1. Open the link in **Chrome**.
2. Tap the green **Install** bar, or **⋮** → **Install app**.
